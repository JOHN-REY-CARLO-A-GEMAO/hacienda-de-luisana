# Served Property Photos

These are the copies the guest website loads. The originals live in
`assets/images/gmaps/`, and the intake rules — how a photo gets from that folder
to a gallery tile, and which supplied shots were deliberately left out — are in
`../../../assets/images/gmaps/README.md`.

`img-01`–`img-14` are re-downloadable with `scripts/download-gmaps.sh`; the
snake_case files (`main_house_*`, `annex_night_lit.jpg`, `camping_units_*`,
`entrance_porch_sign`, `hdl_*`) were supplied by the client and must not be
overwritten by it.
